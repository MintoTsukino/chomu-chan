# ちょむちゃん（Project SLM）フェーズ1 🐱

生まれつき賢くて、あなたのことだけ知らない猫。
企画書V3.1／設計図v2準拠のフェーズ1プロトタイプ。

## あそびかた

**`chomu.html` をダブルクリックするだけ。**（1ファイル版・オフライン動作）

- はなしかける：入力欄に日本語で
- 🍚 ごはん：おなかが回復
- 🧶 けだまクリック：あそび欲求が回復
- ちょむちゃんの上でマウスぐりぐり：なでなで（💗）
- 📔 ボタン：おぼえたこと（よびかた・すきなもの）を見る
- 放置するとねむくなって寝る。話しかけるかマウスを大きく動かすと寝ぼけながら起きる

### デバッグモード

`chomu.html?debug=60` のようにURLに付けると時間が60倍速に。
画面下に欲求の生数値が出る。おねだり・睡眠の動作確認用。

## フェーズ1に入っているもの

- 保存の器（記憶・欲求・夢ログ・セッション状態）… localStorage、実時刻差分
- 欲求4本（おなか・あそびたい・かまってほしい・ねむけ）＋ご機嫌の自動導出
- 欲求由来の自発発言（おねだり・頻度キャップつき）
- 記憶の自発話題化（おぼえた「すき」をちょむちゃんから持ち出す・8分クールダウン）
- 睡眠（放置時のみ・入力拒否なし・寝ぼけトーン・部屋が暗くなる）
- 名前をおぼえる（会話で聞く→確認→保存。「〇〇ってよんで」で改名）
- すきなものをおぼえる（「ラーメンすき」→生得辞書で分類→記憶→後日recall）
- 生得辞書 約200語＋トピック辞書（greet/food/game/chat/self）＋一軍fallback

## フェーズ2でやること（器は準備済み）

- 忘却曲線・うろ覚え・混同／訂正学習（「ちがうよ」→覚え直し）
- 未知語の分類質問（1セッション1回）／できごと記憶と伏線回収
- 夢の生成（睡眠中の忘却処理→夢日記→起きたら語る）
- たからばこ（手動保護・枠は飼育日数で増加）

## 辞書の足し方（コードは触らない）

1. `dict/topics/` のJSONに1ルール足す（または新しいトピックファイルを作る）

```json
{ "match": "さんぽ|散歩", "responses": ["さんぽいいにゃ！どこまであるくの？"] }
```

2. `node build.mjs` を実行 → `chomu.html` が再生成される

- `{name}` と書くと飼い主の呼び名が入る
- 新しいファイルを作ったら `engine.js` の `files` 配列にも1行追加（※開発版で複数ファイルのまま動かす場合のみ。build.mjsはフォルダを自動で全部読む）

## フォルダ構成

```
chomu/
  chomu.html        ← 1ファイル版（これだけで動く・配布用）
  index.html        ← 開発版UI
  engine.js         ← エンジン（345行・凍結ライン300行を超過中。次の機能は辞書側でできないか先に疑う）
  build.mjs         ← 1ファイル版ビルダー（node build.mjs）
  dict/
    innate/words.json   … 生得辞書（分類辞書）
    innate/self.json    … 自己紹介
    topics/greet.json   … あいさつ
    topics/food.json    … たべもの
    topics/game.json    … ゲーム・開発
    topics/chat.json    … 雑談・まにゃまにゃ
    core/templates.json … システム台詞・トーン
    core/fallback.json  … 一軍fallback
```

## 公開するとき（GitHub Pages）

1. GitHubにリポジトリを作って `chomu/` の中身をpush
2. Settings → Pages → Branch: main を選ぶ
3. `https://ユーザー名.github.io/リポジトリ名/` で世界中から会える
   （開発版 index.html は fetch を使うのでサーバー上なら分割ファイルのまま動く）

## 注意

- 記憶はブラウザのlocalStorageに入っている。**ファイルを別の場所に移す・別ブラウザで開くと、別の子（初対面）になることがある**
- 記憶を消して最初からにしたいとき：開発者ツールのConsoleで `localStorage.clear()` → リロード
